# Лист персонажа: полный процесс (гайд GenHQ для Higgsfield)

Лист персонажа собирает образ в одном месте: виды спереди, сбоку и сзади, крупный план лица, вид сверху и детальные снимки ткани и аксессуаров. Он даёт видеомодели чёткий референс. Логика гайда: **одно лицо — любой следующий образ**. Из одного фото лица делается шесть (и больше) разных образов; один и тот же человек, полный визуальный референс на каждый наряд.

Три шага гайда:
1. **Выбрать персонажа** — одно из шести готовых описаний или своё (`references/02-looks-genhq.md`).
2. **Создать лист** — шаблон `references/01-sheet-template.txt` + описание + фото лица.
3. **Оживить** — утверждённый лист в новый кадр или в видео со своим исполнением (`references/03-video-and-fixes.md`).

Файлы в `references/` — дословный текст гайда на английском (модели лучше понимают промпты по-английски). Не перефразируй шаблон: вставляй целиком.

## Шаг 1. Создать лист в Higgsfield (картинка)

1. Верхнее меню **Image**.
2. Модель: **GPT Image 2.5 Sunburst** (можно **Nano Banana 2.1**).
3. Через «+» загрузить **чёткое, хорошо освещённое фото лица**.
4. Скопировать шаблон `01-sheet-template.txt`, заменить строку `PASTE CHARACTER DESCRIPTION HERE` на описание образа целиком, вставить весь промпт в поле.
5. Внизу выбрать **16:9** (альбомный), нажать **Generate**.
6. Проверить: лицо, все **пять ракурсов** и **восемь деталей**. Сохранить готовый лист — это референс для видео.

Через CLI Higgsfield то же самое: найди точные id моделей (`higgsfield model list --image | grep -i -E "gpt|nano"`, `higgsfield model list --video | grep -i -E "seedance|genjutsu|motion"`), параметры конкретной модели — `higgsfield model <id>`, цену — `higgsfield generate cost`. Если стоит скилл `higgsfield-generate`, вызывай модели по нему. Не угадывай id моделей: бери из списка.

Генерации платные. Перед запуском покажи человеку: промпт, модель, формат, примерную стоимость. Запускай после его «ок».

## Описание образа: из чего состоит

Готовые: `references/02-looks-genhq.md` — 6 штук (серебристый костюм, золотой сатиновый стритвир, синий бархат с кружевом, бордовый бархат с цилиндром, лён с капуцином на плече, тёмные мантии с гримом). Они под мужчину с бородой; для другого человека правь причёску, растительность на лице и посадку, структуру оставь.

Своё описание пиши тем же форматом:
- `Hairstyle:` цвет, длина, форма, как лежит; борода/усы.
- `Accessories:` каждый предмет с подзаголовком (`sunglasses:`, `chains:`, `cane:`…), точное место и сторона (на левом запястье, в правой руке).
- `Outfit:` каждый предмет отдельно (`jacket:`, `shirt:`, `trousers:`, `shoes:`): крой, посадка, ткань и фактура, цвет, застёжки и их число, карманы, длина, надписи дословно в кавычках.
- Для грима и протезов отдельный блок `Head and makeup:` (шаблон уже говорит модели, что это костюмный эффект на том же человеке).
- `Bottom-row close-ups, left to right (exactly 8):` восемь пронумерованных деталей `НАЗВАНИЕ: что видно` — ткань верха и низа, надпись, украшения, обувь, причёска, руки с аксессуарами, всё, что чаще «плывёт».
- `Continuity:` что не должно меняться ни в одном ракурсе: застёгнуто/расстёгнуто, на какой руке часы, в какой руке трость, на каком плече животное («never mirror its position»), «add no other props».

Пиши предметами и фактами, не настроением. Человек говорит по-русски — переведи его описание в этот формат на английском и покажи ему перевод коротко по-русски.

## Шаг 2. Новый кадр по листу

Утверждённый лист — **image reference** в GPT Image 2.5 или Nano Banana 2.1. В промпте опиши сцену, позу, кадрирование и свет, сохраняя лицо и наряд неизменными. Добавь, что нужен один снимок, а не лист.

## Шаг 3. Видео с переносом движения

**Video** → **Higgsfield Genjutsu** (рядом в меню **Seedance 2.5**) → левая панель **Motion transfer** → сверху загрузить **своё исполнение** (клип с нужным движением) → в **image reference** через «+» добавить **лист** → по желанию включить **Prompt** и вставить видео-промпт из `03-video-and-fixes.md` (заменить `[VIDEO REFERENCE]` и `[CHARACTER SHEET]` на подписи из интерфейса) → **Generate**.

Лист отвечает за внешность, клип за движение, это два отдельных файла. Начинай с **короткого теста с самым трудным действием** (поворот, рука пересекает тело). Нужна точная речь — оставь оригинальное аудио и проверь синхрон губ.

## Проверка и правки

- **Лист:** сравни каждый ракурс с фото лица и описанием: пять ракурсов, восемь деталей, крой, цвета, обувь, аксессуары. Частая ошибка: сзади другая длина пиджака или воротник.
- **Видео:** повороты, пересечения рук, первый и последний кадр; мерцание фактур, «съезжающие» аксессуары, искажённые руки, изменения лица.
- **Как писать правку:** где (секунда или ракурс) → какая проблема видна → какое изменение нужно → что оставить. Одна проблема за раз, сравнивай с прошлой версией. Готовые формулировки — в `03-video-and-fixes.md`.
- Сложный образ собирай постепенно: сначала одежда, потом грим, трость или животное на плече. Если референс нечёткий — сначала улучши референс, а не дописывай промпт.

## Финал и пакет персонажа

Когда короткие тесты получились, генерируй финал в нужном разрешении; проверяй именно выгруженный файл после ресайза, кропа и монтажа. Сохраняй папку персонажа:
```
<Персонаж>/
  лицо.jpg, исполнение-<сцена>.mp4
  образы/<образ>/промпт-листа.txt (шаблон + описание), лист.png, правки.txt
  видео/<сцена>/промпт.txt, модель-и-настройки.txt, итог.mp4
```
Следующий образ — то же фото лица + другое описание в шаблоне. Следующее исполнение — готовый лист + новое видео.

## Для разных ассистентов
Скилл один и тот же для Claude Code (`~/.claude/skills/character-sheet/`), Codex (`~/.codex/skills/character-sheet/`) и Hermes (`~/.hermes/skills/creative/character-sheet/`). Если Higgsfield недоступен, те же модели и порядок работают в Magnific или другом сервисе, где есть GPT Image 2.5 / Nano Banana 2.1 и перенос движения (Seedance, Kling motion control): меняются только названия кнопок.
